# Brand Identity — ScuolaDiNetwork.com

## Palette CSS (variabili in `:root`)

```
--color-primary:     #1B2B5E   /* Blu notte */
--color-accent:      #C9A84C   /* Oro */
--color-dark:        #0F1A3A   /* Sfondo sezioni scure */
--color-light:       #F8F6F1   /* Sfondo sezioni crema */
--color-text:        #1A1A1A
--color-text-muted:  #5C6070
--color-red-old:     #C0392B   /* Solo per le 3 dipendenze (sezione problema) */
```

## Font (Google Fonts — già caricati nell'`<head>`)

- Titoli: `var(--font-title)` → Playfair Display
- Corpo: `var(--font-body)` → DM Sans
- Numeri/dati/prezzi: `var(--font-mono)` → DM Mono (classe `.mono`)

## Stile

- Sezioni alternate: `.section--dark` / `.section--light` / `.section--cream`
- Border-radius: max `--radius: 6px`
- Niente gradienti colorati — solo overlay scuri su foto
- Immagini: solo foto reali di Tito, niente stock

## Copy — Vincoli

- **CTA:** sempre "Entra", "Parliamo", "Scopri", "Inizia" — mai "Acquista ora" o "Compra"
- **Frase chiave:** "Mi siedo accanto a te" — ancorarla nelle sezioni
- **Tono:** diretto, concreto, autorevole — mai "rivoluzionario", "incredibile", "il segreto che..."
- **Target Schwartz livello 3** (Solution Aware): sa che esistono strumenti digitali, non conosce ancora Tito
